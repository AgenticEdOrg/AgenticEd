Agent Workflows & Handoffs

When work is split across several agents, mistakes can travel and grow. Learn the main patterns, why handoffs are where things break, and where a human must approve.

Part 1

Four ways to organise AI work

A → B → CPrompt chaining

Fixed stages, each using the last one's output. Outline → draft → edit.

classify → specialistRouting

Send each request to the right specialist: billing, technical, policy.

many at onceParallel workers

Independent subtasks run simultaneously, then results are merged.

manager + teamOrchestrator–workers

A planner breaks the goal into subtasks, assigns them, and assembles the result.

Part 2

Handoffs are where errors travel

A wrong fact from the researcher becomes a confident paragraph from the writer, then a published mistake. Each step makes the error look more trustworthy. Try it:

Make handoffs safe

Pass structured data (fields, not loose prose), require evidence (a source for every claim), and verify before the next agent builds on it.

Part 3

Where a human must approve

The test

If this step goes wrong, can it be undone — and does it affect anyone other than the user? Can't be undone, or affects others → a human approves first.

StepUndo?Affects others?Checkpoint?
Search the webNothing to undoNoNo
Draft a messageYesNoNo
Send the messageNoYesYes
Spend moneyHardYesYes
Delete filesOften noMaybeYes

Guardrails work alongside checkpoints: hard limits the agent can't cross even if its reasoning goes wrong — no sending to outside addresses, a spending cap, a list of allowed tools.

Lab A · No code

Design your agent team

Design lab · 30 min

Map a three-agent pipeline with checkpoints

Draw it in Excalidraw (free, no account) or on paper, then record it in the activity below.

Excalidraw or paperEvidence: 1 diagram
  1. Pick a scenario

    Homework helper, news digest, trip planner, job application helper — or your own.

  2. Draw the orchestrator and 2–3 workers

    For each worker: its specialty, what it receives, what it hands on.

  3. Mark every handoff

    Write what each handoff must contain (for example "facts + source link for each").

  4. Add a verification step and checkpoints

    Apply the undo test to every action. Mark checkpoints in a different colour.

  5. Break it on paper

    Pick one worker and imagine it gets something wrong. Trace where the error goes. Does your design catch it?

Evidence for your portfolioYour diagram with checkpoints marked, and the failure trace from step 5.

Responsible AI

Oversight by design, not after the incident

Teams that add human review only after something goes wrong learn the expensive way. Decide where humans approve before you build — and when several agents contribute, keep a record of who handed what to whom, so a mistake can be traced and owned.

Key terms

OrchestratorThe agent that plans subtasks and assigns them to workers.
HandoffPassing work or data from one agent to the next.
Error compoundingA mistake growing as later steps build on it unchecked.
VerificationChecking a claim against its source before it's used.
CheckpointA point where a human must approve before the agent continues.
GuardrailA hard limit the agent cannot cross, whatever it decides.
