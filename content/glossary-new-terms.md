New Glossary Terms for Beginners
This file contains 25 proposed glossary additions for the AgenticEd course.
Each term has a simple definition and an everyday or AI-related example.
Note: These terms were selected to avoid repeating the term names already listed in glossary.html. Please compare them with the course lessons before submitting the pull request.

1. API
Definition: An API is a way for one software program to ask another software program for information or help.

Example: A weather app uses an API to get today's temperature.
2. API Endpoint
Definition: An API endpoint is a specific address that a program uses to request a particular service or piece of information.

Example: A program may use a weather endpoint to request the current temperature.
3. Function
Definition: A function is a named set of instructions that performs a particular task.

Example: A calculator program can use an addition function to add two numbers.
4. Parameter
Definition: A parameter is a named value that a function or action can use when it runs.

Example: A greeting function may have a name parameter so it can say, "Hello, Manoj."
5. Input
Definition: Input is the information given to a program so it can do a task.

Example: The question "What is the weather today?" is input given to a weather assistant.
6. Output
Definition: Output is the result that a program gives after it processes information.

Example: The answer "It is sunny today" is the output from a weather assistant.
7. Environment
Definition: An environment is the place or situation in which a program or AI system works.

Example: A robot's environment may be a room with people, tables, and chairs.
8. Goal
Definition: A goal is the result that an AI system is trying to achieve.

Example: The goal of a travel assistant may be to find a suitable train for a trip.
9. Action
Definition: An action is something a program or AI system does to make progress toward its goal.

Example: A travel assistant searches for train times as one action.
10. Observation
Definition: An observation is information that a system receives about what happened after an action.

Example: After searching for trains, the assistant observes the list of available trains.
11. Planning
Definition: Planning is deciding which steps to take to reach a goal.

Example: Before arranging a trip, an assistant plans to check dates, compare trains, and show the best options.
12. Task Decomposition
Definition: Task decomposition means breaking a large task into smaller tasks that are easier to complete.

Example: To plan a holiday, an assistant can split the work into booking travel, finding a hotel, and listing places to visit.
13. Workflow
Definition: A workflow is an ordered set of steps used to complete a task.

Example: A support workflow may receive a request, check its details, and send it to the right team.
14. JSON
Definition: JSON is a text format used to organise information as named values and lists.

Example: A program can receive a person's details in JSON, such as a name and an age.
15. Structured Output
Definition: Structured output is information returned in an organised format that follows an expected layout.

Example: An assistant may return a list with separate fields for a product name, price, and availability.
16. Authentication
Definition: Authentication is the process of checking whether someone is really the person they claim to be.

Example: A website checks a user's password before allowing them to sign in.
17. Authorization
Definition: Authorization is the process of checking what an approved user is allowed to do.

Example: A student may be allowed to view marks but not change them.
18. Rate Limit
Definition: A rate limit is a rule that sets how many requests a user or program can make in a certain amount of time.

Example: A service may allow an app to make only 100 requests in one minute.
19. Timeout
Definition: A timeout happens when a program stops waiting because a response has taken too long.

Example: A search request may time out if the website does not respond within the allowed time.
20. Retry
Definition: A retry is another attempt to complete an action after an earlier attempt did not work.

Example: If a network request fails, a program may retry it once the connection returns.
21. Logging
Definition: Logging means keeping a record of events and actions that happen in a program.

Example: An app may record when a user signs in or when an error occurs.
22. Monitoring
Definition: Monitoring means regularly checking a system to see whether it is working as expected.

Example: A team monitors a website to notice when it becomes slow or stops responding.
23. Evaluation
Definition: Evaluation is checking how well a system performs a task.

Example: A teacher evaluates an AI assistant by checking whether its answers are correct and useful.
24. Benchmark
Definition: A benchmark is a test or set of tests used to compare how well systems perform.

Example: A team can use the same set of questions to compare two AI assistants.
25. Fallback
Definition: A fallback is a backup method used when the normal method cannot complete a task.

Example: If an AI assistant cannot find an answer, its fallback may be to ask a human for help.
